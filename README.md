# yt-dlp Easy Downloader v2

YouTube / YouTube Music のページに操作UIを追加し、ローカルの yt-dlp と連携する Chromium 拡張機能です。

## 実装機能
- YouTube / YouTube Music にダウンロードボタンを追加
- 動画 / 音声形式の選択（YouTube Music は音声固定）
- 出力形式の選択
- 開始・終了位置の指定
- ダウンロードキューと進捗表示
- キャンセル要求
- ダウンロード履歴
- 履歴から保存先フォルダを開く・保存ファイルを既定のプレイヤーで再生
- 動画・音声へのサムネイル／ジャケット画像の埋め込み
- 保存先フォルダ変更
- PyPI上のyt-dlp最新バージョン確認

## セットアップ（Windows）
1. Python 3.10以降をインストール
2. FFmpegをインストールしてPATHを通す
3. `server` フォルダで `python -m pip install -r requirements.txt`
4. `server/config.json` の `api_key` を長いランダム文字列に変更
5. `extension/background.js` の `API_KEY` を同じ値に変更
6. `server` フォルダで `python server.py` を起動
7. Chrome/Edgeの拡張機能ページでデベロッパーモードを有効化し、`extension` フォルダを読み込む

APIキー例は必ず自分だけが使う値に変更してください。初期値のままではサーバーは起動しません。

## 操作
- YouTube: 動画または音声を選択してダウンロード
- YouTube Music: 音声のみ
- 対応形式ではサムネイル／ジャケット画像を埋め込みます（動画: MP4/MKV、音声: MP3/M4A/FLAC/OPUS）。WebM/WAV は形式の制約により対象外です。FFmpeg と mutagen が必要です。
- キュー: 進捗、速度、残り時間、キャンセル要求
- 履歴: 完了・失敗したジョブの記録。完了した項目から保存先フォルダを開いたり、保存ファイルを既定のメディアプレイヤーで再生できます。
- 設定: 保存先とyt-dlp更新確認

## 注意
- このツールはローカルPC上で動作します。サーバーは `127.0.0.1` のみにバインドします。
- 進捗率はyt-dlpが報告するダウンロード済みバイト数と総バイト数から計算します。総サイズが不明な場合は進捗バーを不確定表示にします。
- キャンセルはyt-dlpの進捗フックで検知する方式です。ネットワーク処理のタイミングによっては停止反映まで少し時間がかかる場合があります。
- 履歴は `server/history.json` に保存されます。
- 保存先はローカルサーバー側の設定で変更します。
- 動画・音声のダウンロードは、権利者の許可や適用される規約・法律を確認し、適法に利用できるコンテンツに限ってください。
- YouTube側のDOM変更でボタン挿入位置が変わる場合があります。
